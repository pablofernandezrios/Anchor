# DNS-over-HTTPS endpoints, by address (SPEC 8.2)
#
# A browser that resolves names itself over HTTPS walks straight past Anchor's
# resolver. Managed policies turn that off in the browsers Anchor knows about;
# this list is the backstop for the ones it does not, and for a browser whose
# policy did not apply.
#
# Addresses rather than names, because a browser doing DoH has usually been
# given the address already and never asks DNS for it. Names are blocked too,
# in doh-domains.txt, for the case where it does.
#
# These belong to public DNS providers, so blocking them during a session also
# makes the provider's own website unreachable. That is the trade, and it is
# why the list stays short and well known rather than trying to be exhaustive.
#
# One address or CIDR range per line. Edit freely.
