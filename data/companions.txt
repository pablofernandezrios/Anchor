# Anchor companion domains (SPEC 8.1)
#
# A site and the other domains it cannot work without. Each line reads:
#
#     site.com: assets.example.net other.example.org
#
# The companions are allowed only when the site itself is on your allowlist.
# Allowing github.com therefore brings githubassets.com with it, and allowing
# nothing brings nothing. That conditionality is the whole point: it is not a
# second allowlist, it is the first one made to actually work.
#
# Why this file has to exist at all: Anchor sees DNS names and nothing else.
# A query for github.githubassets.com looks identical whether it came from
# the GitHub tab you have open or from anything else on the machine, so
# "allow what the allowed page needs" cannot be inferred -- only known in
# advance. This is that knowledge, written down.
#
# It is best effort and always will be. A site not listed here still works
# once you add its companions yourself; `anchor stats` names what was
# refused. Lines starting with # are ignored, and a domain covers its
# subdomains. Edit freely: package upgrades will not overwrite your changes.
