# Architecture decision records

`SPEC.md` is the source of truth. When the code needs to deviate from it, or
when the specification leaves a decision open and the answer is worth
remembering, it is recorded here and agreed with the owner first.

Each record says what the situation was, what was decided, and what follows
from it. Records are not edited once accepted; a later record supersedes an
earlier one.
